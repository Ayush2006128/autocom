# AutoCom

AutoCom is an Expo mobile app for fall detection, caregiver alerts, and SOS escalation.

> **Warning:** This project is fully vibe coded. Treat the implementation as experimental and review, test, and harden it thoroughly before relying on it for real safety-critical use.

## Development

```bash
npm install
npx expo start
```

Android foreground monitoring requires a development or production build with the native module included. Expo Go does not include the app's custom native foreground-service module.
